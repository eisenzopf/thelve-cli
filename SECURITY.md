# Security policy

## Supported versions

Thelve CLI is currently a private preview. Only the newest signed preview
release is eligible for security fixes. Preview releases may be revoked at any
time through the signed release channel.

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability. After
this repository is published, use GitHub's **Security → Report a
vulnerability** flow so the report and follow-up remain private. Before public
launch, contact the Thelve maintainers through the private channel used to
obtain preview access.

Include the affected CLI version, operating system, cloud provider, expected
and observed behavior, and minimal reproduction details. Do not include cloud
credentials, Telnyx credentials, phone numbers, tokens, raw call media, or
customer data. The maintainers will acknowledge a complete report, coordinate
validation and remediation privately, and publish an advisory when disclosure
is safe.
